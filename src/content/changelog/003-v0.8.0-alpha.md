v0.8.0-alpha is about the parts of the app you touch every day. Automation is something you author, a clip can be bounced, fitted and faded from the clip itself, export writes stems, and the app's own tests can now fail a build. Over 150 commits since v0.7.1-alpha.

- **new**: Edit any curve and undo any edit. An automation lane edits the curve you pick (volume, pan or a plugin parameter), every edit is one undo step, points snap to the grid, and Shift extends a selection.
- **new**: Automation clips. A stretch of a curve is an object you can drag to move, Ctrl-drag to copy, and right-click to duplicate, split or delete. Cutting a clip never changes how it sounds.
- **new**: Fit to bars now suggests the musical lengths. The clip editor offers the five best bar counts, best first, and says what each does, like "x0.88 speed, pitch follows".
- **new**: Bounce in Place. Right-click an audio clip and it becomes a recording of how it sounds through its track's effects. The effects switch off so nothing is doubled, Undo brings everything back, and the fader and pan stay live.
- **new**: Insert slots grow past ten, up to 64. Projects with ten inserts or fewer save exactly as before.
- **new**: Every panel can be Docked or Floating, and Contextual or Keep Open. Right-click a panel's title bar. View, Gather Panels and Reset Panel Positions bring everything back.
- **new**: Stems export. One file per track that has sound, plus the master, all the same length so they line up in any other program. The export window is rebuilt on the app's own controls.
- **new**: The plugin browser remembers the plugins you loaded recently.
- **new**: Fades are draggable on the timeline, and clips have a context menu with consistent undo.
- **fix**: Left-trimmed MIDI clips now play where they are drawn. They used to play late by the amount you trimmed.
- **fix**: A volume curve with no points is unity gain, not silence.
- **fix**: The loudness reading was about 1 dB low on 48 kHz files. Loudness and true peak are now measured once per file.
- **fix**: Curve tension is audible now. Older projects store a tension value that never played, so opening one resets it to linear and it sounds the same as before.
- **perf**: Audio memory on a 4 GB laptop. 16 and 24-bit sources stay as PCM with bit-identical output, imports decode off the UI thread, and the anti-alias copy of a high-rate file is streamed and only made for sources that play. A 12-track session uses 43% less audio memory.
- **ci**: UI scenarios, UI architectural guards and a size and memory budget now fail the build. Placeholder code was deleted instead of shipped.
- **docs**: Known gaps, stated plainly. Bounce in Place, automation clips, the export window, the panel menus and the eleventh insert row are tested against the real code but have not been clicked through in the running app. VST3 and CLAP plugin automation still needs a host adapter, so only internal plugins are driven. Bounce in Place refuses instrument tracks and cuts effect tails. Panel menus open from a right-click on the title bar, with no visible button yet. An idle timeline costs about 12 ms a frame on a 4 GB laptop, and a 96 kHz source in a 48 kHz project still needs a full float copy while it plays. Presets and in-app documentation move to v0.8.1.
