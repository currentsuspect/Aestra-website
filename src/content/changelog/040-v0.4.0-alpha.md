Hardening milestone. Metering you can trust and exports that hold up.

- **security**: First full security audit — 11 findings, 8 fixed, 3 documented and deferred. Project files are now validated before they're trusted.
- **new**: Broadcast-standard loudness metering (BS.1770), so what the meter says matches what streaming platforms will measure.
- **new**: Proper dither on 16- and 24-bit export — quiet tails fade to silence instead of grit.
- **fix**: Memory cleanup moved off the audio thread entirely, removing a class of stutter that hit exactly when the session got heavy.
- **ci**: Nightly builds under memory and undefined-behaviour sanitizers, filing their own issue when something breaks.
